This file contains the specific enhancement settings for the Fruit Crusaders project.

## Visual Effects

The Fruit Crusaders project uses several visual effects to create its distinctive anime aesthetic:

1. Neon Particle Effects:
   - Type: Overlay
   - File: neon_particles.png
   - Usage: Applied during character transformations and power-up sequences

2. Cosmic Starfields:
   - Type: Background
   - File: cosmic_stars.png
   - Usage: Used as background for space battle scenes

3. Magical Girl Sparkles:
   - Type: Overlay
   - File: sparkles.png
   - Usage: Applied during magical transformations

4. Transformation Sequences:
   - Type: Transition
   - File: transformation.mp4
   - Usage: Used when characters switch between chibi and awakened forms

## Enhancement Pipeline Settings

The enhancement pipeline is configured with the following settings for the Fruit Crusaders project:

- Background Removal: Enabled

- Auto-Captioning: Enabled with anime_style
- Branding: "Fruit Crusaders" watermark in bottom-right corner
- Background Music: epic_anime_battle_theme.mp3 at 15% volume
