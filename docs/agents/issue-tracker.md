# Issue Tracker

**Type:** GitHub
**Repo:** `free-claude-code` (no remote configured — local development)

Issues are tracked locally in `.scratch/` as markdown files. Each feature or bug has its own subdirectory under `.scratch/<feature>/` with an `ISSUE.md` describing the problem and `NOTES.md` for progress tracking.

Workflow:
- New issue → `.scratch/<slug>/ISSUE.md`
- Triage state tracked as frontmatter in ISSUE.md
- Completed → move to `.scratch/archive/`
