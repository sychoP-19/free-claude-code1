# Triage Labels

| Role | String | Notes |
|------|--------|-------|
| Needs evaluation | `needs-triage` | Default for new issues |
| Waiting on reporter | `needs-info` | Needs more detail |
| Ready for agent | `ready-for-agent` | Fully specified, AFK-ready |
| Needs human | `ready-for-human` | Human implementation required |
| Won't fix | `wontfix` | Not actioned |
